# Telas HTML/CSS para importação no Figma

Este pacote contém versões estáticas e navegáveis das telas restantes do ControlAI.

## Abrir localmente

Na raiz do projeto, execute:

```bash
npx serve figma-import -l 4173
```

Abra `http://localhost:4173` e use um plugin como **HTML to Design** para importar cada URL.

## URLs

- `/login.html`
- `/register.html`
- `/settings.html`
- `/billing.html`
- `/bot.html`

Os links entre páginas funcionam no navegador. No Figma, recrie essas ligações no modo **Prototype**, usando Login como ponto inicial e Configurações como ligação para Planos e Integração Bot.

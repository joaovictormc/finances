A — Modal Centrado

Overlay fixo com dialog centrado. Fecha no Escape e clique no backdrop. Padrão web clássico, fácil de implementar sem bibliotecas.

  • Universal, todos entendem
  • 100% CSS nativo + estado React
  • Bloqueia o conteúdo atrás
  • Pode ser pequeno em mobile

B — Drawer Lateral

Painel deslizante pela direita. Exibe mais campos sem scroll. Mais moderno — padrão do Linear, Notion, apps financeiros como Monarch Money.

  • Mais espaço para campos
  • Mantém contexto da lista atrás
  • Ótimo em mobile (ocupa tela toda)
  • Requer animação CSS para ficar elegante

C — Inline / Row Expandida

Form aparece inline na lista, expandindo a linha selecionada. Sem overlay, sem bloqueio do conteúdo. Padrão de planilha/table.

  • Sem mudança de contexto
  • Fluido para edição rápida
  • Pouco espaço para campos
  • Ruim em mobile
  • Mais complexo de implementar

Clique para selecionar. A escolha se aplica a todos os formulários do app (transações, orçamentos, contas, categorias).
